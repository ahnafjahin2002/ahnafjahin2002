> **Domain:** Systems Programming &nbsp;|&nbsp; **Role:** Sole developer

A crash-consistent, VSFS-like file system implemented in C from the ground up, with an append-only journal of `DATA` and `COMMIT` records guaranteeing atomic metadata updates.

**What I did**
- Designed the on-disk layout: superblock, inode bitmap, data bitmap, inode table, data region
- Implemented `create` and `install` operations with full transaction replay after simulated crashes
- Wrote a custom consistency checker validating inode bitmaps, directory entries, and block references
- Handled all memory management manually — no safety net

```text
┌──────────┬────────────┬────────────┬────────────┬──────────────┐
│ Super    │ Inode BMP  │ Data BMP   │ Inode Tbl  │ Data Region  │
└──────────┴────────────┴────────────┴────────────┴──────────────┘
        └── Journal: [ DATA ][ DATA ][ COMMIT ] → replay on mount
```
