`Next.js` `Laravel` `MySQL` `JavaScript` `REST APIs` `CSS3`

</details>

<details>
<summary>📊 <b>Customer Category Classifier</b> — Machine Learning (2025)</summary>
<br/>

An end-to-end ML pipeline on 24,210 real-world records covering preprocessing, feature engineering, model training, and evaluation.

- Achieved **88.1% accuracy** and **0.95 AUC** with a custom neural network.
- Benchmarked KNN, Decision Tree, Neural Network, and K-Means models; identified 4 customer segments via unsupervised clustering.

`Python` `Scikit-Learn` `Pandas` `NumPy` `Neural Networks` `K-Means` `ROC/AUC`

</details>

<details>
<summary>🗂️ <b>Metadata Journaling File System</b> — Systems Programming (2025)</summary>
<br/>

A crash-consistent VSFS-like file system implemented in C from scratch, using an append-only journal of DATA and COMMIT records for atomic metadata updates.

- Built create/install operations with full transaction replay.
- Validated inode bitmaps, directory entries, and block references with a custom consistency checker.

`C` `Low-Level Memory Management` `File Systems` `Systems Programming`

</details>

<details>
<summary>🌐 <b>Federal Flight Agency Network</b> — Networking & Infrastructure (2025)</summary>
<br/>

A mission-critical enterprise network designed in Cisco Packet Tracer with VLSM subnetting, RIPv2, static routing, DHCP relay, DNS, HTTP, and SMTP/POP3 services across 8 routers.

- Implemented redundant failover paths using floating static routes.
- Validated end-to-end connectivity, DHCP assignment, and email communication.

`Cisco Packet Tracer` `VLSM` `RIPv2` `DHCP` `DNS` `Socket Programming`

</details>

<details>
<summary>🚁 <b>Parallel Inference Engine for Autonomous Disaster Drones</b> — Computer Architecture & AI (2025)</summary>
<br/>

A parallel CNN inference engine for edge deployment under &lt;2W power and &lt;150ms latency constraints, architected as a Multi-Core SoC with SPMD execution.

- Designed with SRAM scratchpads, DMA streaming, and ECC memory.
- Optimized memory hierarchy to achieve &lt;10% cache miss rate; proposed dual Rescue/Survey operating modes for adaptive field deployment.

`Computer Architecture` `Parallel Computing` `Edge AI` `RISC-V/ARM` `Memory Hierarchy`

</details>

<summary>🏎️ <b>3D Racing Game</b> — Computer Graphics & C++ (2025)</summary>

A 3D racing game engineered from scratch in C++ and OpenGL, featuring real-time collision detection and nitro boost physics simulation.

`C++` `OpenGL` `PyOpenGL` `Game Physics` `AI Pathfinding` `Computer Graphics`
